# 任务管理系统

基于 Vue 3、Vite、TypeScript、Tailwind CSS 的单用户任务管理应用。提供任务列表、三列看板、浏览器本地持久化和深色模式。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端给出的本地地址。执行 `npm run build` 构建生产版本，`npm run test` 运行单元测试，`npm run typecheck` 检查类型。

## 功能

- 新建、查看、编辑和删除任务；标题必填，描述选填。
- 任务状态为待办、进行中、完成；优先级为高、中、低。
- 列表支持标题与描述搜索，桌面端使用表格，手机端使用卡片。
- 看板支持鼠标及触屏拖动，跨列变更状态，列内调整顺序。
- 深色模式可一键切换并记住选择；首次打开时跟随系统配色。

任务和主题分别保存在当前浏览器的 `localStorage` 中，刷新后会恢复。数据不会同步到其他设备或浏览器。浏览器禁止本地存储时，应用会提示；当前页面仍可继续操作。

## 目录

```text
src/
  components/    任务列表、看板、编辑与删除弹窗
  composables/    任务与主题状态
  lib/            任务操作及本地存储
  types/          任务类型与选项
  App.vue         页面布局与交互入口
  style.css       Tailwind 与界面样式
```
